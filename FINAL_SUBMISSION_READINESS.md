## 1. Project Identity & Purpose

STAMAS is an end-to-end, AI-assisted bid compliance verification platform designed for GeM procurement workflows. It automates tender requirement extraction, bidder document intelligence, evidence matching, deterministic rule evaluation, grounded RAG analysis, human-in-the-loop officer review, compliance reporting, and audit trail logging.

### Core Operating Principle
> **AI finds and understands the evidence. Rules verify it. Humans make the final decision.**

## 8. SIH Demonstration Workflow (5–8 Minutes)

1. **Start System:** Execute `.\start.ps1` in PowerShell.
2. **Open Dashboard:** Navigate to `http://localhost:3000`.
3. **Select Tender:** Open demo tender `TND-SIH2026-GEM01` (*Procurement of Enterprise Cloud Compute*).
4. **View Requirements:** Inspect extracted financial turnover, experience, and ISO requirements.
5. **Open Bidder Dossier:** Select bidder `Param Tech Systems India Pvt Ltd`.
6. **Inspect Evidence:** View document snippets matched to page 5 and page 2.
7. **Review Rules:** Inspect deterministic rule evaluation outputs (`SATISFIED` vs `INDETERMINATE`).
8. **View System Decision:** View overall system evaluation (`REVIEW`).
9. **Officer Review Workstation:** Confirm valid requirements and override ambiguous items with written justification.
10. **Finalize Decision:** Lock final decision to `PASS`.
11. **Export Reports:** Download generated PDF / CSV compliance reports.
12. **Audit Trail & Benchmarks:** View timestamped audit trail log and switch to the "Evaluation & Benchmarks" tab for real-time accuracy metrics.

## 9. Factual Limitations & Disclosures

1. **SIH Prototype Scope:** STAMAS is an AI-assisted bid compliance verification prototype developed for SIH26100; it is not an official government production system.
2. **AI Provider Quota:** External LLM API calls (Gemini API) are subject to network availability. When offline, STAMAS gracefully degrades to keyword retrieval and rule evaluation.
3. **Scan Quality:** PyMuPDF text extraction accuracy depends on source PDF quality. Degraded scans rely on OCR fallback.
4. **Single-Node Local DB:** Development uses SQLite. Multi-user cloud deployment requires PostgreSQL connection pooling as documented in `DEPLOYMENT.md`.
